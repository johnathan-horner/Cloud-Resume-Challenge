ShootItPicks

Live in production | shootitpicks.com
  • Launched ShootItPicks as a live subscription product with 1,100+ automated tests gating every release by designing a serverless AWS architecture (Lambda, API Gateway, DynamoDB, Cognito, S3, CloudFront) with Stripe billing and CI/CD on least-privilege OIDC roles, built and maintained with Claude Code.
  • Kept every number in ShootItPicks' AI assistant tied to source data, with unverifiable answers replaced before display, by designing tool calling across 11 retrieval tools, code checks on each figure and a model from a different vendor grading each answer.
  • Blocked a model that cost 7 times more but scored below the current one by creating a 51-scenario evaluation suite, including adversarial cases, that gates every model change.
  • Put live prices from 7 regulated US sportsbooks on 900+ priced sides across 15 games by integrating The Odds API with 100% player matching, line and price always taken from the same book, vig removed on two-sided markets and a hard credit cap with alerts.
  • Brought the model's accuracy level with the betting market (Brier 0.1460 vs. 0.1467 on held-out weeks) by measuring it against market prices, finding most displayed edges were noise, and pulling each estimate toward the market with weekly refits.
  • Removed a 25.7-point phantom edge from live prices by tracing it to invalid averaging of American odds and rebuilding the math in probability space, verified against 108 live market sides.
  • Cut request latency from 5.5 seconds to 0.15 seconds by finding that each request scanned 321 season records to use about 16 and re-partitioning DynamoDB by week.

FinTech AI

Live public demo | fintech-ai-horner.streamlit.app
  • Passed 22 of 23 held-out RAG test questions with 95.2% exact-fact accuracy on FinTech AI by building a 3-agent LangGraph pipeline (market analysis, risk assessment, portfolio management) with FAISS retrieval, HyDE, a cross-encoder re-ranker and an independent second model grading every answer.
  • Put the agent pipeline under bank-style model risk controls, with the VaR backtest in the Basel green zone (Kupiec p-value 0.72 to 0.78 over 254 days), by gating each agent behind its own approval record, PSI drift monitoring and audit traces. A blocked agent falls back to a data-derived answer instead of guessing.
  • Defined the production AWS architecture for FinTech AI in CDK, including Bedrock Guardrails, KMS encryption, CloudTrail and 7-year log retention, validated by cdk synth in CI, and validated Amazon Bedrock as the primary model on held-out evaluation, with automatic fallback to a second vendor.
  • Exposed FinTech AI and Transaction Anomaly Detection to AI assistants through 2 FastMCP servers with 6 tools each, read-only and deterministic, so the same request always returns the same answer with no model calls.
